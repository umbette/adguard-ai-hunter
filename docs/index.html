Core Security Architecture

Two tightly aligned defenses — household DNS protection via Sentinel Core and on-the-go browser hardening via Sentinel Shield MV3.

Layer 01 • Home Network Daemon

Sentinel Core (`src/`)

Autonomous cyber-defense daemon bridging AdGuard Home / Pi-hole and Home Assistant Ingress with zero cloud telemetry.

  • 15 deterministic shields (Smart TV ACR, Vacuum, Badbox AOSP C2, Automotive, 3D Printers)
  • CDN-safe Malicious IP & DNS-answer correlation (Feodo / Spamhaus DROP)
  • Multi-Label Shannon Entropy DGA detector (H > 3.85) + Gemini advisory
  • Zero-Trust Device Admission Control & 1-Click Unbreak Console
Layer 02 • Browser Extension MV3

Sentinel Shield (`0.4.1`)

Lightweight Chrome & Edge Manifest V3 extension protecting laptops even outside your home LAN with zero always-on host permissions.

  • Brand lookalike, Punycode homograph & bare-IP phishing interception
  • 47 SSOT-compiled protected brands + Web3 drainer signature shield
  • Zero-permission Anti-Dynamic Pricing DNR ruleset (70+ ad/pricing networks)
  • Opt-in Cookie & Tracking Param Guard + 1-click session bypass
Layer 03 • Proactive Intelligence

Threat Miner & SSOT Pipeline

Automated zero-trust compiler validating threat feeds and synchronizing all brand registries across Python backend and MV3 extension.

  • CDN/Resolver exclusion guard prevents Cloudflare or Google DNS collateral blocks
  • 8,700+ Public Suffix List boundary checks & RFC 1123 sanitization
  • Single Source of Truth (`spec/` + `scripts/compile_ssot.py --check`)
  • Zero-Knowledge community unbreak workflow without leaking IP or MAC PII
